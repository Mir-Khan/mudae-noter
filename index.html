Compare Collections

"Compare" creates two new collections: characters only Collection A has, and characters only Collection B has.

"Transfer Notes (A → B)" generates $n commands to copy notes from Collection A onto matching characters in Collection B wherever B is missing that note - handy after re-importing a collection on a new server, since notes don't carry over. Notes only transfer when both sides show the same key count, since some notes are tied to a specific number of keys. Matching uses global rank, image, and kakera value first (so characters renamed with Mudae's $alias still match), falling back to series + name only when those aren't available.

"Transfer Colors (A → B)" generates $ec commands to copy colors from Collection A onto matching characters in Collection B wherever B's color differs - handy after re-importing a collection on a new server, since colors don't carry over. Only transfers between characters you hold on both sides (at least 1 key in Collection A and Collection B), so it won't paint a color onto a character in B you don't actually own yet. Matching uses global rank, image, and kakera value first, falling back to series + name only when those aren't available.
