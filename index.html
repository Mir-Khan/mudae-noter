Compare Collections

"Compare" creates two new collections: characters only Collection A has, and characters only Collection B has.

"Transfer Notes (A → B)" generates $n commands to copy notes from Collection A onto matching characters in Collection B wherever B is missing that note - handy after re-importing a collection on a new server, since notes don't carry over. Notes only transfer when both sides show the same key count, since some notes are tied to a specific number of keys. Matching uses global rank, image, and kakera value first (so characters renamed with Mudae's $alias still match), falling back to series + name only when those aren't available.

"Transfer Colors (A → B)" generates $ec commands to copy colors from Collection A onto matching characters in Collection B wherever B's color differs - handy after re-importing a collection on a new server, since colors don't carry over. Only transfers between characters you hold on both sides (at least 1 key in Collection A and Collection B), so it won't paint a color onto a character in B you don't actually own yet. Matching uses global rank, image, and kakera value first, falling back to series + name only when those aren't available.

Add New Characters

Got new characters since your last import? Run this in Discord:

$mmsaty+ri-c+x+kon

That's your usual import flags plus n, Mudae's "not noted" filter - it DMs you only the characters you haven't noted yet, so you don't have to re-paste your whole collection every time you get someone new.

Paste just that DM's contents below - characters already in your collection are skipped automatically, so it's safe even if it overlaps with what you've already added.

Pick an Image

Run the command below in Discord - Mudae will DM you every image link already claimed for this character. Paste the whole DM below (numbers and all - anything that isn't a link is ignored) and click one to pick it. ⚠ Characters with a lot of claimed images can come back as several separate DMs - paste all of them in together (any order is fine) so nothing's missing.

or upload a new image

No need to paste a $ims DM first - upload a file here to get an $ai command for it right away. Mudae's $ai command only accepts images hosted on imgur.com or imgchest.com, so uploading here needs a free ImgChest account and a personal access token - a one-time, couple-minute setup, saved on this device only.

  1. Create a free account (or log in) at imgchest.com.
  2. Click your profile icon → Settings → the Security tab.
  3. Under Personal Access Tokens, click New Token and give it any name (e.g. "Mudae Noter").
  4. Copy the token it gives you - imgchest.com only shows it once - and paste it below.
